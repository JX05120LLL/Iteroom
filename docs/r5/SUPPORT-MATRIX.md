| OpenCodeReview | 历史 Windows x64 v1.12.9 / 固定 SHA；全量检查使用项目外工具 | tarball 不捆绑二进制；其他平台、自动安装升级未验 |

| 四种文本补丁 v2 | 独立契约、合成 Git 导出应用/反向恢复、纯冲突与恢复计划、v1 拒绝混写 | 未接产品快照/Store/沙箱工具/API/UI；尚无 v2 实际写回/恢复、真实模型或沙箱组合 |
