# Iteroom v1 验收矩阵

> 下表定义产品验收条件；已验证的限定范围和未验证项分别记录在 [STATUS](STATUS.md)，不能从局部结果推断 v1 通过。

## 1. 证据分类与记录

每次验收记录环境/平台、Node 版本、代码提交与工作区是否有未提交改动、模型路由、DSH/Cordis/OCR/SDK/服务版本、镜像 digest、输入快照、步骤、结果、日志/截图路径和未验证项。记录中只保存脱敏标识，不公开凭证或真实源码。

分别标注：源码核对、离线单元测试、模拟协议/模型、实际沙箱、真实模型端到端、干净环境发行检查。mock 成功不能升级为真实模型/沙箱通过；UI 截图不能证明执行安全。

最新 R0 [真实模型/DSH/实际沙箱组合](r0/DSH-LIVE.md)用 3 次官方模型请求验证只读工具→沙箱修复/测试→下一步及重启不重放；模拟模型的错误/取消与远端父子收束另见[组合报告](r0/DSH-SANDBOX.md)。Gate A/B/C 在固定环境和合成输入内通过，R0 技术验证完成；**下表 A01–A21 产品状态不随之通过**，产品未知执行恢复、浏览器与发行仍待验。

R1-1 [受管任务入口](r1/TASK-ENTRY.md)只局部验证 A19 的现有 Connection 认证/来源保护和任务登记侧的请求去重、项目外存储、重启查询；它没有运行 A02 的真实理解任务，也没有完成 A12/A13 的执行事件恢复或 A21 的 UI。A01–A21 均未因此标为完整通过。

R1-2 [受限读取](r1/READ-SCOPE.md)局部验证 A04 中“任务选定文本文件在读取时的范围/类型/大小检查及哈希”，以及 A19 的新读取路由认证。它不保存可复读输入快照，没有模型引用、权限全链路或用户 UI；A02/A04/A19/A21 均未标为完整通过。

R1-3 [固定输入](r1/INPUT-SNAPSHOT.md)切片局部验证 A03/A04 的选定文本副本、项目外持久关联、源文件变化后重读及损坏拒绝；Web carrier 验证新增路由的认证。多文件采集不是原子快照；该切片当时未接模型、引用和 UI，后续进度见下段，A02/A03/A04/A19/A21 仍未完整通过。

后续[受管只读实测](r1/READONLY-LIVE.md)将独立 DSH Loop、唯一只读工具、任务/Session、来源校验和方案 C 文字 UI 接线。模拟模型的越 EOF/过宽请求裁剪回归、任务取消/重启不重发、事件游标、本地文本增量管道及 Windows 合成 Host 崩溃后 CLI 退出通过本机测试。真实 DeepSeek 前两轮分别预留 4 次和 3 次且失败；第三轮修正后预留 2 次，在新合成仓库完成准确回答和固定第 1 行引用，浏览器可点击来源，仓库未变，重启不重发。**A02 的 Windows/合成仓库只读场景与 R1 退出条件在此范围通过**；A21 仅有桌面与窄屏完成态/失败态局部证据，真实生成中间帧、提供方断线、完整产品 A12/A13/A19 及独立发行未验收。v1 不随 R1 通过。

[R2 限定证据](r2/EVIDENCE.md)新增 `modify` 任务、实际 OpenSandbox 文件/测试/清理、真实模型 DSH 最小 Loop、项目外补丁和浏览器创建/缺配置失败态。合成仓库中小功能修改与测试、补丁可应用、宿主未改；无模型实际沙箱的失败、注入流故障和执行中删除、模拟 Loop 实际沙箱取消均有独立记录。因此 R2 路线的最小退出条件在 Windows/固定版本/现有选定文本文件范围内通过。A05 仍缺新增/删除/重命名与脏工作树全面覆盖，A07/A11/A13/A17/A21 仍有实际提供方断线、用户项目、浏览器完成态、清理故障与发行缺项，不能标为完整产品通过。

[R3 分层证据](r3/EVIDENCE.md)对 A14 的现有路径外部编辑冲突、A15 的注入式部分写回与显式继续/回滚、A16 的接受/放弃、A18 的历史删除及注入清理重试提供测试；合成脏 Git 工作树的 index/HEAD 保持不变。模拟 DSH Loop/实际沙箱候选产物接受与本地真实浏览器下载、接受、回滚、删除已验证，R3 最小退出条件在限定范围通过。A14 的新增路径、真实断电、用户仓库、恶意并发编辑和发行仍缺证据，A14–A18 的全部产品矩阵不能整体标为通过。

## 2. 场景

独立[模型传输测试](r0/MODEL-TRANSPORT.md)8/8 为离线请求守卫及回环 HTTP/SSE；后续[磁盘计数](r0/MODEL-JOURNAL.md)7/7 为本机文件/独立进程与 I/O 故障注入。真实模型组合另有独立运行证据，本地费用规划不等于服务方账户硬限额或账单。下表产品场景仍待执行。

|---|---|---|---|
| A01 | P0-01、P0-14 | 新环境启动、首次配置、错误地址/凭证、缺少 Docker | 启动步骤可复验；故障可理解，执行不可用时不回退宿主 |
| A02 | P0-02、P0-03 | 真实模型读取合成仓库并解释代码 | 自有工具被调用；文件引用准确；本地/沙箱无写操作 |
| A03 | P0-04 | staged、unstaged、未跟踪、重命名与删除混合输入 | 快照与确认范围一致，基线包含用户已有内容，排除有原因 |

| A07 | P0-08 | 检查成功、失败、输出截断、超时、证据缺失 | 命令/cwd/环境/退出码可追溯；未知不显示通过，日志不伪造用例数 |
| A08 | P0-09 | OCR 工作树、单提交、范围及默认排除测试文件 | 精确审查输入与清单一致；补充测试或明确排除，三种模式真实 CLI 验证 |

| A11 | P0-10 | 前台/后台长命令及子进程取消、模型流取消 | 状态经历 cancelling；核对执行收束，未收束不报 cancelled |
